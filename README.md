## ✨ Core Features & Architectural Highlights

### 1. 🧮 Editable Progressive Tariff Slabs & Matrix
* **Real-Time Customization:** Fully editable upper kWh limits and unit charge rates ($/kWh) for Slab 1, Slab 2, and Slab 3.
* **Instant Calculation Engine:** Automatically partitions monthly consumption across progressive tiers to calculate precise estimated monthly bills instantly.

### 2. 🔌 Custom Appliance Manager
* **Direct kWh Telemetry:** Add specific heavy appliances (e.g., HVAC units, inverters, EV chargers) by entering their monthly kilowatt-hours.
* **Dynamic Node Spawning:** Automatically updates total consumption sliders and spawns interactive 3D nodes into the hologram house matrix.

### 3. 🤖 3D Cyber Robot AI Assistant & Voice Engine
* **Conversational Knowledge Engine:** Fully trained to handle project introductions, developer roll numbers, progressive tariff formulas, and viva questions.
* **Speech Recognition & TTS:** Features integrated speech-to-text (STT) microphone control and text-to-speech (TTS) voice synthesis with synchronized mechanical jaw articulation.

### 4. 🌐 Immersive WebGL 3D & Cyberpunk Graphics
* **3D Cyber Robot Avatar:** Built with Three.js featuring dual glowing optical sensors, antenna geometry, and real-time rotational rendering.
* **Hologram House Matrix:** Interactive wireframe architectural grid representing real-time load distribution.
* **Animated Particle Background:** Dynamic canvas particle network with glowing nodes and connecting telemetry lines.
